# Crazina — Zero to Pro Coding Academy

Crazina is an interactive coding learning website designed to take learners from their very first line of code all the way to professional software engineering.

## What’s Inside

- **6 Progressive Career Stages (24 Interactive Tutorials)**
  1. **Absolute Foundations** — Variables, Conditionals, Loops, and Pure Functions
  2. **Interactive Web Engineering** — Semantic HTML, Flexbox, CSS Grid, and DOM Events (with live preview & DOM/layout tests)
  3. **Core Programming Mastery** — Functional Array Pipelines (`map`/`filter`/`reduce`), Immutable Objects, Closures, and `async`/`await`
  4. **Computer Science & Problem Solving** — Big-O & Hash Maps, Two Pointers / Sliding Window, Stacks & Parsers, and Graph BFS Shortest Path
  5. **Full-Stack & Application Architecture** — Reactive State Stores, REST API Routing, Relational Hash Joins, and Web Security Sanitization
  6. **Professional Software Engineering** — SOLID Strategy Refactoring, TDD & Edge-Case Validation, O(1) LRU Cache, and Production Rate Limiter & Async Retries
- **Practice Arena (10 Standalone Drills)** — Beginner to Senior Interview & Systems coding challenges with automated test suites and multi-level hints.
- **Interactive Sandbox Playground** — Freeform HTML/CSS/JS live studio and JavaScript execution scratchpad.
- **Pro Engineering Guide & Career Tracker** — Cheat sheets for Big-O, SOLID Clean Code, HTTP/REST, Web Security, and Git workflows, plus XP, Ranks, Streaks, and local progress persistence.

## Running Locally

```bash
npm install
npm run dev
```
